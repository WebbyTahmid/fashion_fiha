# FIHA — Future of Bangladeshi Fashion

Premium Bangladeshi fashion brand website featuring handcrafted silk sarees, Jamdani weaves, elegant panjabis, and bridal gold accessories.

## 📁 Project Structure

```
fiha/
├── index.html                  # Main website landing page
├── style.css                   # Core stylesheet & animations
├── PROJECT_DESIGN_TECH_SPEC.md # Technical specification & design system
├── README.md                   # Project documentation
├── images/                     # High-resolution photoshoot and product assets
│   ├── hero.png
│   ├── hero_saree2.png
│   ├── hero_saree3.png
│   ├── lifestyle.png
│   ├── product1.png
│   ├── product2.png
│   ├── product3.png
│   └── collection.png
└── video/                      # Video assets & loops
    └── hero-saree-loop.mp4
```

## 🚀 How to Run Locally

### Using Python:
```bash
python -m http.server 3000
```
Then open http://localhost:3000 in your browser.

### Using Node.js:
```bash
npx serve -l 3000
```
